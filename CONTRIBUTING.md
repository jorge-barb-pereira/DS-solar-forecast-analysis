# Contributing

Run the tests, publication check and CLI before submitting changes. Preserve causal feature availability and chronological separation. Never select a model using final test labels or substitute observed future weather for an available forecast. Describe metric units, forecast horizon and information available at issuance.

Use only synthetic or explicitly approved public data. Do not commit serialized models, credentials, private records or identifying source metadata. New public artifacts must be generated from this repository's approved inputs and covered by its file allowlist.
